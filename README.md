
# Tứ Sắc Online

Đây là bản demo multiplayer chạy trên trình duyệt điện thoại.

## Chạy trên máy tính
1. Cài Node.js.
2. Mở terminal trong thư mục này.
3. Chạy:
   npm install
   npm start
4. Mở http://localhost:3000

## Chơi qua Internet
Server phải được deploy lên một dịch vụ Node.js hỗ trợ WebSocket (ví dụ Render, Railway, Fly.io hoặc VPS).
Sau khi deploy, gửi URL cho bạn bè.

## Lưu ý
Bản 1 tập trung vào phần multiplayer và giao diện mobile. Luật Tứ Sắc trong bản demo được giản lược, chưa bao gồm toàn bộ hệ thống ăn/quản, khạp, nhóm bài và tính điểm theo luật bàn chơi thực tế.
